Prompt für Claude 
Richte in diesem Projekt das Backend für unsere Schul-Webseite ein und lade es danach automatisch zu GitHub hoch. Arbeite selbstständig. Halte nur an, wenn unten steht, dass du nachfragen sollst, oder wenn etwas schiefgeht. Ich habe keine Programmiererfahrung: Erkläre mir Probleme und das Ergebnis in einfachem Deutsch.

1. Prüfen
- Der geöffnete Ordner muss ein Git-Repository sein, dessen Remote "origin" auf GitHub zeigt. Wenn nicht: anhalten und mir erklären, was fehlt.
- Wenn Git-Name oder Git-E-Mail nicht eingestellt sind: frag mich danach und stelle sie mit git config --global ein.

2. Neuesten Stand holen
- Führe auf dem Branch main "git pull" aus. Bei Konflikten: anhalten, nichts überschreiben und mir erklären, was los ist.

3. Dateien anlegen
- Ersetze in der Vorlage server.js unten die Adresse https://grumihome.github.io durch die GitHub-Pages-Adresse dieses Repositorys: https://<besitzer>.github.io. Den Besitzer liest du aus der Remote-URL, alles kleingeschrieben.
- Gibt es package.json oder server.js schon, überschreibe sie nicht. Sind sie gleich wie die Vorlage, sag mir, dass das Backend schon eingerichtet ist. Wenn sie sich unterscheiden, zeig mir kurz die Unterschiede und frag, ob ich sie ersetzen will.
- Sonst lege beide Dateien genau mit dem Inhalt der Vorlagen unten an.
- Lege eine .gitignore mit den Zeilen node_modules/ und .env an. Gibt es die Datei schon, ergänze nur, was fehlt.

4. Sicherheitsregeln
- Schreib niemals einen API-Schlüssel in eine Datei und frag mich nicht danach. Der Schlüssel wird später nur bei Render als Umgebungsvariable ANTHROPIC_API_KEY eingetragen.
- Führe in diesem Ordner kein "npm install" aus. Prüfe nur die Syntax mit "node --check server.js", falls Node installiert ist.

5. Hochladen
- Committe nur package.json, server.js und .gitignore, direkt auf main, mit einer kurzen deutschen Commit-Nachricht. Leg keinen neuen Branch an.
- Pushe nach origin main. Benutze niemals --force.
- Kommt beim Push "Permission denied" oder Fehler 403: anhalten und mir erklären, dass der Besitzer des Repositorys mich auf GitHub unter Settings → Collaborators einladen muss und ich die Einladung annehmen muss.

6. Abschluss
Sag mir in wenigen Sätzen, was du hochgeladen hast. Erkläre dann die nächsten Schritte bei Render: New → Web Service, dieses Repository wählen, Build Command "npm install", Start Command "npm start", Umgebungsvariable ANTHROPIC_API_KEY eintragen.

Vorlage server.js:

import express from "express";
import cors from "cors";
import Anthropic from "@anthropic-ai/sdk";

const app = express();

// Nur diese Webseiten dürfen den Server nutzen (mehrere mit Komma trennen).
const allowedOrigins = (process.env.ALLOWED_ORIGINS || "https://grumihome.github.io")
  .split(",")
  .map((origin) => origin.trim());

// Obergrenzen für alle Anfragen zusammen, damit die API-Kosten begrenzt bleiben.
// Bewusst nicht pro Gerät: In der Schule teilen sich alle Schüler eine IP-Adresse.
const limits = [
  { max: Number(process.env.LIMIT_PER_MINUTE) || 30, windowMs: 60 * 1000, count: 0, start: Date.now() },
  { max: Number(process.env.LIMIT_PER_DAY) || 500, windowMs: 24 * 60 * 60 * 1000, count: 0, start: Date.now() }
];

const MAX_MESSAGE_LENGTH = 2000;

function limitReached() {
  const now = Date.now();
  for (const limit of limits) {
    if (now - limit.start >= limit.windowMs) {
      limit.start = now;
      limit.count = 0;
    }
  }
  if (limits.some((limit) => limit.count >= limit.max)) {
    return true;
  }
  limits.forEach((limit) => limit.count++);
  return false;
}

app.use(cors({ origin: allowedOrigins }));
app.use(express.json());

const anthropic = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY
});

app.get("/", (req, res) => {
  res.send("GRUMI Backend läuft.");
});

app.post("/api/chat", async (req, res) => {
  try {
    if (!allowedOrigins.includes(req.get("origin"))) {
      return res.status(403).json({
        error: "Zugriff nur über die Schulseite erlaubt."
      });
    }

    const { message } = req.body ?? {};

    if (typeof message !== "string" || !message.trim()) {
      return res.status(400).json({
        error: "Keine Nachricht übergeben."
      });
    }

    if (message.length > MAX_MESSAGE_LENGTH) {
      return res.status(400).json({
        error: `Die Nachricht ist zu lang (höchstens ${MAX_MESSAGE_LENGTH} Zeichen).`
      });
    }

    if (limitReached()) {
      return res.status(429).json({
        error: "Gerade sind zu viele Anfragen unterwegs. Bitte versuche es später noch einmal."
      });
    }

    const response = await anthropic.messages.create({
      model: "claude-sonnet-4-5",
      max_tokens: 1000,
      messages: [
        {
          role: "user",
          content: message
        }
      ]
    });

    res.json({
      answer: response.content[0].text
    });

  } catch (error) {
    console.error(error);

    res.status(500).json({
      error: "Fehler bei der KI-Anfrage."
    });
  }
});

const PORT = process.env.PORT || 3000;

app.listen(PORT, () => {
  console.log(`Server läuft auf Port ${PORT}`);
});
